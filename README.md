# Go Individual
Aplicación personal para el registro de envíos, ganancias y propinas. Basada en Estación Go, sin administración de repartidores.

## Publicar en GitHub Pages
Crea un repositorio nuevo, por ejemplo `go-individual`, sube el contenido descomprimido del ZIP a la raíz del repositorio y activa **Settings → Pages → Deploy from a branch → main → / (root)**.

Cada persona que la abra tendrá sus propios datos guardados en el navegador/dispositivo. No se sincronizan con otros teléfonos ni con Estación Go. La fecha es seleccionable y la hora se guarda automáticamente al crear cada envío (se conserva al editar). Usa **Exportar respaldo** regularmente.
